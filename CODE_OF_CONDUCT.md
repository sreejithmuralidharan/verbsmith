# Code of Conduct

Verbsmith follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, constructive, and considerate. Harassment, discrimination,
personal attacks, and deliberate disruption are not acceptable. Maintainers may
remove content or participation that violates these expectations.

Report conduct concerns privately to the repository owner through the contact
method in the GitHub security and community profile. Reports will be handled
confidentially and reviewed promptly.
