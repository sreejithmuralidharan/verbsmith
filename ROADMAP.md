# Roadmap

## Alpha: trustworthy HTTP workflows

- Versioned `.http` workspace, formatter, linter, variables, assertions, captures, and dependencies.
- Libcurl-backed ad-hoc and saved requests, stable output formats, and terminal UI.
- Encrypted local vault, cookie jars, authentication, retry policy, history, and redaction.
- Signed binaries for macOS, Linux, and Windows on x64 and ARM64.

## Beta: complete API workspace

- Postman, Insomnia, Bruno, HAR, OpenAPI, and editor `.http` import/export with loss reports.
- Sandboxed Postman-compatible scripts and WASI plugins.
- GraphQL, WebSocket, SSE, gRPC, HTTP/3, mocks, captures, and data-driven runs.
- Browser-compatible WASM workspace package and API Studio import/export.

## Release candidate: teams and hardening

- Encrypted versioned self-hosted sync and team vaults.
- Upgrade, downgrade, corruption, recovery, and large-workspace testing.
- Package-manager distribution, reproducible builds, SBOMs, provenance, and security audit.

## 1.0

Version 1.0 ships only after the documented platform, protocol, migration,
security, and compatibility suites pass. Progress is tracked by public milestones,
not by promised calendar dates.
