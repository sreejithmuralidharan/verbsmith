# Product evidence register

Features and comparison claims must cite verifiable sources and map to an
acceptance test or explicit non-goal. This register is intentionally maintained
as product input rather than marketing copy.

Initial recurring problem clusters:

- Resource use and responsiveness: Postman issue 7294; Insomnia issue 3786.
- Account and cloud dependence: Insomnia issue 6577.
- Sync and data-loss anxiety: Postman issue 9481; Insomnia issues 5167, 6579, and 6585.
- Import/export fidelity: Postman issue 11252; Insomnia issues 4274 and 8504.
- Reuse and deterministic workflows: Postman issues 1535, 697, and 2392.

Before a comparison page is published, each claim must be rechecked against the
current product version and linked to its primary source. Individual complaints
may conflict; Verbsmith promises a transparent decision trail, not the impossible
claim that every preference can be satisfied simultaneously.
